# TARDIS
## Executive Summary 

The Tools, Analytics and Reference Data Information System (TARDIS) is a planned analytics platform designed to host and promote shared reference data resources and tools across government. Leveraging Shared Services Canada's existing Federal Data Science Hub (FSDH), TARDIS will provide all public servants with access to vetted reference datasets and standardized analytics tools through a streamlined, single-window approach. 

## Strategic Value Proposition 

While Canada ranks among the top 10 digital governance performers in the 2023 OECD Digital Government Index, it ranks only 15th for data-driven public sector capability. TARDIS addresses a critical gap in Canada's digital government capability.  This platform transforms fragmented departmental efforts into coordinated federal infrastructure, eliminating the scenario where different departments maintain conflicting versions of the same business registries, causing citizens to receive inconsistent information depending on their government touchpoint. 

## Expected Outcomes 

Within one year, thousands of public servants will gain access to collaborative infrastructure that eliminates duplicated analytical work while improving consistency and reliability of analysis supporting ministerial decision-making and parliamentary accountability. The platform will deliver immediate operational improvements while building long-term institutional capability that strengthens Canada's position as a global exemplar of responsible democratic innovation. 

 

## TARDIS Pillars 

TARDIS is built around three interoperable pillars that transform fragmented government data infrastructure into a coordinated federal resource: a Reference Data Hub, a Tool Sharing Environment, and a Collaboration Space. 

## Reference Data Hub 

A centralized repository of vetted, standardized datasets with universal government applicability, including date formats, province and territory naming codes, and department/agency identifiers. This "dictionary" of standards eliminates the current system of competing, dissimilar datasets across federal organizations, ensuring consistent data for parliamentary questions and ATIP requests. Integration with the FSDH environment provides immediate access to standardized data alongside analytical tools. 

## Tool Sharing Environment 

A government-wide repository for analytical tools, applications, scripts, and methodologies accessible to all federal data analysts. This addresses the current inefficiency where solutions to common analytical challenges remain confined to individual teams or divisions despite having universal applicability. The platform enables organizations to leverage the collective expertise and scale of the federal system, with larger departments sharing capabilities that benefit smaller organizations. 

## Collaboration Space 

A shared working environment enabling real-time collaboration on multi-departmental data projects. Leveraging FSDH's built-in capacity for shared environments, analysts can work together without the current limitations of email-based data sharing, version control issues, or incompatible tools and standards. This eliminates work staggering and enables full utilization of analytical capabilities across organizational boundaries. 

## 1. Departmental Contribution Matrix 

### 1.1 Shared Services Canada (SSC) 

Role: Technical Infrastructure Provider & Platform Host 

Responsibilities: 

Host TARDIS on Federal Data Science Hub (FSDH) infrastructure 

Provide cloud storage capacity (initial 50TB, scalable to 500TB) 

Enable shared environment capabilities similar to GitHub integration 

Provide Level 1-2 technical support during business hours through coordinated shared resources with interested departments (starting with PSPC +- 10 tech staff in rotation) 

Maintain platform security and backup protocols 

Enable API access for reference datasets 

Resource Commitment: 

Technical: 2.0 FTE developers (shared resource across Cloud One strategy, in schedule rotation) 

Financial: Cloud infrastructure costs via cost-recovery or MOU model within TBS 

Timeline: Lead infrastructure setup in Phases 1-2 

 

 

### 1.2 Treasury Board Secretariat (TBS) 

Role: Data Standards Authority & Reference Data Steward 

Responsibilities: 

Provide API access to Inventory of Data and Metadata Reference Standards 

Maintain and update core reference datasets (provinces, departments, fiscal periods) 

Provide ongoing governance and policy guidance (shared responsibility with STC) 

Ensure alignment with federal data strategy 2023-2026 

Coordinate with Working Group on Data Standards and others 

Resource Commitment: 

Technical: 2.0 FTE data stewards (from existing CDO office + 2-4 from PSPC Celio’s team, shared schedule rotation) 

Financial: Data governance (shared responsibility with STC) and validation costs 

Ongoing: Reference data maintenance and quality assurance (shared responsibility with STC)
